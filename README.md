# T-ITS Smart Parking Research

## Project objective

Characterize the instability of decentralized bounded-rational
parking search under increasing offered parking load, and subsequently
evaluate stability-aware parking assignment strategies.

## Project generations

### 00_archive
Original historical source packages.

### 01_ICCE_2026_Frozen
Frozen reproduction environment for the ICCE-TW 2026 study.
No methodological modifications are allowed.

### 02_Exp1_FreeSearch_v2
Current T-ITS Experiment 1 implementation.
